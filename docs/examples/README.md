# Shipped section examples

These are real screenshots of the disposable acceptance website using the shipped Hero and Contact Form sections. They demonstrate component layout and responsive behavior, not a finished business design or startup content to seed.

- [Desktop example](hero-contact-desktop.png)
- [Mobile example](hero-contact-mobile.png)

The page uses a Hero with `heading` and `sectionSettings.colorScheme: "dark"`, followed by a Contact Form linked to a Payload form. Choose the actual design, copy and imagery from the project's brief. Replace starter branding as part of a real website build. Form notifications need the intended delivery configuration before launch; the test fixture deliberately stores submissions without sending email.

For article layouts, use the shipped Posts Hero and Posts Content in a Template assigned through routing settings; see the [component catalogue](../engineering/component-catalogue.md). Add new verified examples here as the site's own design develops.
