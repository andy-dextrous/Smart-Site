# Active ExecPlans

This index is the entrypoint for active work in this repo.

Use this file to find the one active ExecPlan that is relevant to your current slice.
Do not scan unrelated active plans unless the current plan explicitly routes you to them.

## How to use this index

- Start here when you need to know what active plan to read.
- Opening or creating an ExecPlan does not bypass the repo's branch-per-slice, worktree, or review-lane rules.
- Open only the plan that clearly matches your current slice.
- If no plan clearly fits, create a new ExecPlan and add it to this index in the same change.
- When a plan is completed, superseded, split, or merged, update this index immediately.
