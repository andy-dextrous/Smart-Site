# SmartSite

This repository contains the complete website and its development kit. Choose the smallest relevant workflow; do not begin with legacy reference material or a whole-repository scan.

| Task | Read first |
| --- | --- |
| First startup or resume | [Getting started](workflows/getting-started.md) and `smartsite-start` skill |
| Build a website | `smartsite-build` skill, [brief](project/brief.md), [design](project/design.md), [components](engineering/component-catalogue.md) |
| Edit visible words, pages, navigation or other CMS content | [Content MCP](workflows/content-mcp.md) and `smartsite-content` skill |
| Change section schema, code or layout | [Section development](engineering/section-development.md), [design system](engineering/design-system.md) and `smartsite-sections` skill |
| Extend collections or migrate data | [Configuration](engineering/configuration-system.md) and `smartsite-data` skill |
| Diagnose a failure | [Troubleshooting](workflows/troubleshooting.md) and `smartsite-repair` skill |
| Launch, deploy or upgrade | [First launch](workflows/first-launch.md), [deployment](workflows/deployment.md), [upgrading](workflows/upgrading.md) and `smartsite-launch` skill |
| Daily source work | [Development](workflows/development.md), [coding standards](engineering/coding-standards.md) |
| Change CMS layout, sidebar, widgets or editor styling | [CMS presentation](engineering/admin-layer.md) |
| Understand core boundaries | [Admin layer](engineering/admin-layer.md), [MCP](engineering/mcp.md), [guardrails](rules/agent-guardrails.md) |

Use [PLANS.md](PLANS.md) only for substantial execution plans. A client’s plans may live in its own `docs/exec-plans/`; a fresh starter has none. The historical manuscript under `docs/references/` is provenance, not current setup guidance.
